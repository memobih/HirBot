# 🎓 Graduation Project – AI-Powered Recruitment Platform

## 🚀 Overview
An AI-powered recruitment platform designed to streamline the hiring journey for both job seekers and companies.  
It focuses on intelligent job matching, automated application workflows, skill assessments, and professional networking within a single integrated system.

## 🔗 Live Demo
[Visit the Recruitment Platform]([https://hirbot.vercel.app/auth/login])

## ✨ Features
- Post jobs with **AI-powered candidate matching**.  
- Advanced **Applicant Tracking System (ATS)** pipeline with exams and contextual filtering.  
- **Auto-Apply** functionality for matched opportunities.  
- Comprehensive **profile management** (skills, education, CV, portfolio, experience).  
- **Skill assessments** and a **daily challenge system** for continuous improvement.  
- **Real-time application tracking** and instant status updates.  
- Integrated **interview workflow** with exams and onboarding.  
- **AI chatbot** for user guidance.  
- **Social layer** with posts, polls, media, and professional connections.  
- **Admin tools** for managing companies, subscriptions, and skill structures.  
- **Zoom integration** for interviews and meetings.  
- **External authentication** via OAuth/SSO.  

## 🛠 Tech Stack
- **Frontend:** Next.js (React Framework)  
- **Backend:** Laravel (PHP), .NET Core (Microservices)  
- **Database:** MySQL, Redis  
- **Integrations:** Zoom API, OAuth/SSO
